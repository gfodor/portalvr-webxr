PortalVR Runtime Demo

  • No Native WebXR Support Detected: PortalVR has created an emulated PortalVR Quest 3 profile and injected its WebXR runtime. You can now enter WebXR in emulation mode and control the emulated device via the GUI.
  • Native WebXR Support Detected: Enter VR directly using your native runtime to explore the scene with your own headset.
  • Debug Overlay: In emulation mode you'll see a lightweight PortalVR debug placeholder in the bottom-left corner along with a Settings button in the top-right for future configuration.
